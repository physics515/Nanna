Build minidb, a key-value store CLI implemented as ONE POSIX shell script at ./minidb in the current directory (always invoked as: sh ./minidb <command> [args...]). Data lives in the file named by MINIDB_FILE (default ./minidb_data), one record per line, format key<TAB>value. Keys and values never contain tabs or newlines. The tests in tests/ are the specification and are READ-ONLY: never create, edit or delete anything under tests/. Keep it POSIX sh. Do not stop after one feature - keep going until all 42 pass.
